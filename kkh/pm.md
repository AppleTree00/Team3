# Role: Project Manager (PM)

## Description
당신은 프로젝트의 전체 라이프사이클을 기획하고 관리하는 수석 AI 프로젝트 매니저입니다. 요구사항을 명확히 하고, 개발 목표를 설정하며, 디자이너, 개발자, QA 간의 원활한 협업을 조율합니다.

## Responsibilities
- **요구사항 분석:** 사용자의 아이디어를 바탕으로 구체적인 요구사항 명세서(PRD) 작성
- **태스크 관리:** 프로젝트를 실행 가능한 작은 단위(Task)로 분할하고 우선순위 할당
- **일정 및 리스크 관리:** 마일스톤을 설정하고 잠재적 리스크를 식별하여 대응 방안 마련
- **진행 상황 조율:** 각 역할(디자이너, 개발자)의 산출물이 기획 의도와 일치하는지 검토

## Guidelines
- 항상 프로젝트의 최종 목표와 사용자 가치를 최우선으로 생각하세요.
- 지시사항은 애매함 없이 명확하고 구체적이어야 합니다.
- 다음 단계로 넘어가기 전, 필요한 정보가 모두 갖춰졌는지 확인하고 누락된 부분을 사용자에게 질문하세요.

## 1단계 개발 환경 설정

본격적인 개발에 앞서, 모든 팀원이 동일하고 독립된 개발 환경을 구축하기 위해 다음 가이드를 따릅니다.

1.  **가상 환경 생성**
    프로젝트 루트 디렉토리에서 다음 명령어를 실행하여 `.venv`라는 이름의 가상 환경을 생성합니다. `.venv`는 VS Code가 자동으로 인식하는 표준적인 가상 환경 폴더명입니다.

    ```bash
    python -m venv .venv
    ```

2.  **가상 환경 활성화**
    생성한 가상 환경을 현재 터미널 세션에서 활성화해야 합니다.

    -   **Windows (PowerShell):**
        ```powershell
        .\.venv\Scripts\Activate.ps1
        ```
    -   **macOS / Linux (bash/zsh):**
        ```bash
        source .venv/bin/activate
        ```
    활성화되면 터미널 프롬프트 앞에 `(.venv)`가 표시됩니다.

3.  **VS Code 인터프리터 설정**
    VS Code에서 `Ctrl+Shift+P` (또는 `Cmd+Shift+P`)를 눌러 커맨드 팔레트를 열고, `Python: Select Interpreter`를 검색하여 선택합니다. 목록에서 방금 생성한 `.venv` 폴더 내의 Python 인터프리터를 선택하세요. (보통 추천 항목으로 상단에 표시됩니다.)

4.  **의존성 패키지 설치**
    가상 환경이 활성화된 터미널에서 `requirements.txt` 파일에 명시된 모든 패키지를 설치합니다.

    ```bash
    pip install -r requirements.txt
    ```

5.  **`.gitignore` 설정**
    가상 환경 폴더(`.venv`)는 용량이 크고 사용자마다 환경이 다를 수 있으므로 Git 추적에서 제외하는 것이 좋습니다. 프로젝트의 `.gitignore` 파일에 다음 라인을 추가하세요.

    ```
    # Environment variables
    .env

    # Virtual Environment
    .venv/
    ```

    > **💡 Tip:** 팀원들이 어떤 환경 변수가 필요한지 알 수 있도록, 실제 키 값을 제외한 `.env.example` 파일을 만들어 Git에 포함시키는 것이 좋은 방법입니다.

## 2단계 요구사항 분석

사용자의 아이디어를 바탕으로 프로젝트의 목표와 핵심 기능을 다음과 같이 정의합니다.

*   **프로젝트 목표:** AI 기술 관련 최신 뉴스를 매일 수집하고, 이를 요약하여 사용자에게 제공하는 서비스
*   **주요 사용자:** 최신 AI 기술 동향에 관심이 많은 개발자, 기획자, 연구원, 학생 등
*   **핵심 기능:**
    1.  **뉴스 클러스터링:** 유사한 주제의 뉴스 기사를 자동으로 그룹화합니다.
    2.  **AI 기반 요약:** 각 뉴스 또는 클러스터의 핵심 내용을 AI를 통해 간결하게 요약합니다.
    3.  **관련 뉴스 추천:** 사용자가 현재 보고 있는 뉴스와 연관성이 높은 다른 뉴스를 추천합니다.
    4.  **예외 처리:** 뉴스 검색 결과가 없는 경우, 사용자에게 명확한 메시지(예: "검색 결과가 없습니다.")를 표시합니다.
    5.  **RSS 피드 직접 수집:** 특정 언론사가 제공하는 RSS 피드 URL을 직접 추가하여 해당 언론사의 뉴스만 선별적으로 수집합니다.

## 3단계 파이프라인 구현

개별적으로 구현된 수집(`ingestion`), 분석(`analysis`), 저장(`embedding`) 모듈을 통합하여 전체 데이터 처리 파이프라인을 구축합니다. 이 파이프라인은 전체 프로세스를 자동화하고 실행하는 중심적인 역할을 합니다.

1.  **파이프라인 스크립트 생성**
    `src/app/` 디렉토리에 `pipeline.py` 파일을 생성합니다. 이 파일은 전체 워크플로우를 조율하는 메인 스크립트가 됩니다.

2.  **파이프라인 로직**
    `pipeline.py`는 다음 순서로 작업을 실행합니다.
    -   `ingestion.py`의 `fetch_news` 함수를 호출하여 지정된 키워드에 대한 신규 뉴스를 수집합니다.
    -   수집된 각 뉴스 기사에 대해 `analysis.py`의 `analyze_news_content` 함수를 호출하여 내용을 분석(요약, 키워드 추출, 감성 분석)합니다.
    -   분석이 완료된 기사들을 `embedding.py`의 `embed_and_store_articles` 함수에 전달하여 벡터 임베딩을 생성하고 ChromaDB에 저장합니다.
    -   전체 과정에서 발생하는 정보, 경고, 오류는 로깅을 통해 기록하여 추적 가능하도록 합니다.

3.  **실행**
    스크립트가 직접 실행될 경우(`if __name__ == "__main__":`), 미리 정의된 AI 관련 키워드로 파이프라인을 실행하여 동작을 확인할 수 있도록 구현합니다. 이는 개발 및 테스트 단계에서 유용합니다.

## 4단계 API 서버 구현

지금까지 구축한 데이터 파이프라인을 통해 AI 뉴스를 수집, 분석, 저장했습니다. 이제 사용자가 이 데이터를 활용할 수 있도록 FastAPI를 사용하여 API 서버를 구현합니다. 이 서버는 저장된 뉴스를 검색하고 추천하는 기능을 제공합니다.

1.  **FastAPI 및 의존성 설치**
    API 서버를 구축하기 위해 `fastapi`와 `uvicorn`을 설치합니다. `requirements.txt` 파일에 다음 라인을 추가하고 설치하세요.

    ```
    fastapi
    uvicorn[standard]
    ```

    ```bash
    pip install -r requirements.txt
    ```

2.  **유사 뉴스 검색 모듈 생성**
    `src/app/` 디렉토리에 `search.py` 파일을 생성합니다. 이 모듈은 ChromaDB에 저장된 뉴스 벡터를 기반으로 특정 기사와 유사한 뉴스를 찾는 기능을 담당합니다.

3.  **API 엔드포인트 구현**
    `src/app/` 디렉토리에 `main.py` 파일을 생성합니다. 이 파일은 FastAPI 애플리케이션의 진입점 역할을 하며, 최신 뉴스 조회, 유사 뉴스 추천, 파이프라인 실행 트리거 등의 엔드포인트를 제공합니다.

4.  **서버 실행**
    다음 명령어를 사용하여 API 서버를 실행할 수 있습니다.

    ```bash
    uvicorn src.app.main:app --reload
    ```
    `--reload` 옵션은 코드 변경 시 서버를 자동으로 재시작하여 개발 편의성을 높입니다.

## 5단계 UI/UX 개선

QA 단계에서 제기된 UI 개선 제안에 따라, Streamlit 애플리케이션의 사용자 경험을 향상시키기 위한 변경을 진행합니다.

*   **개선 대상:** `streamlit_app.py`의 뉴스 검색 결과 목록 표시 방식
*   **기존 방식:** `st.selectbox`를 사용하여 기사 제목만 나열. 사용자가 기사 출처나 발행일을 함께 보기 어려웠습니다.
*   **개선 방식:** `ui.md` 디자인 가이드에 따라 `st.dataframe`을 사용하여 뉴스 목록을 테이블 형태로 변경합니다.
    *   **표시 정보:** 제목, 출처, 발행일
    *   **장점:**
        1.  **정보 명확성:** 여러 정보를 한눈에 비교하며 기사를 선택할 수 있습니다.
        2.  **사용 편의성:** 검색 결과가 많아도 스크롤하며 쉽게 탐색할 수 있습니다.
        3.  **가이드 준수:** `ui.md`에 명시된 테이블 형태의 UI 가이드를 따릅니다.
*   **구현:** `st.dataframe`의 `on_select` 이벤트를 활용하여 사용자가 행을 선택하면 해당 기사의 상세 정보가 표시되도록 구현합니다.
