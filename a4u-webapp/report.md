# [기술 보강] APPLY4U MVP 개발 보고서

## 1. 기술 스택 (Tech Stack)
* **Frontend**: HTML5, Tailwind CSS (반응형 UI), JavaScript (ES6+)
* **Backend**: Python / Flask (轻량 프레임워크 기반 API 서버)
* **Database**: SQLite (빠른 프로토타이핑 및 이식성)
* **Deployment/Tool**: VS Code, Git/GitHub, Tailwind CDN

## 3. 주요 기능 및 AI 활용 전략
* **주요 기능**: 사용자 프로필 관리, 커리어 타임라인 생성, 이력서 자동 빌더, 관리자 대시보드.
* **AI 활용 (Co-pilot & Agent 활용)**:
    - **코드 생성**: AI 에이전트를 활용하여 HTML 템플릿 및 Flask 라우터 자동 생성.
    - **데이터 최적화**: 시니어 타겟 유저를 위한 문서 파싱 가이드 프롬프트 설계.
    - **디버깅**: 에이전트를 통한 실시간 에러 로그 분석 및 QA 피드백 반영.

## 4. 팀원별 기술 지원 요청 사항 (Call for Support)
- **기획자**: 기능 우선순위(MVP 범위) 재검토 및 최종 확정 요청.
- **UI/UX 디자이너**: 대시보드 및 프로필 페이지의 시니어 친화적 가독성 개선 가이드 요청.
- **프로그램 개발자**: 현재 `app.py`와 `a4u.db` 간 연동 최적화 및 보안 모듈 적용 요청.
- **QA**: 크로스 브라우저 테스트 및 사용자 시나리오 기반 에러 리포트 작성.
