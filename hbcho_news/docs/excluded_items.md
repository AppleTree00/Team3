# 제외/축소 구현 항목

| 항목 | 처리 | 이유 | 대체 구현 |
|---|---|---|---|
| API Key 하드코딩 | 제외 | 공개 저장소에서 키 유출 위험 | 화면 입력 + sessionStorage 임시 저장 |
| 본문 전문 크롤링 | 제외 | CORS, 저작권, 언론사 약관 리스크 | 제목·출처·날짜·설명 기반 경량 요약 |
| LLM 생성형 요약 | 축소 | 브라우저 정적 페이지에서 키 보호 어려움 | 규칙 기반 요약 |
| 서버 Vector DB | 축소 | GitHub Pages는 서버/DB 실행 불가 | 브라우저 메모리 내 토큰 유사도 |
| 백엔드 프록시 | 제외 | GitHub Pages 단독 배포 목표 | GDELT JSON/JSONP 직접 호출 |
| NewsAPI 직접 브라우저 호출 | 제외 | 공개 배포/CORS/API Key 제약 | GDELT 기본 연동 |
