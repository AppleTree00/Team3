# Project Brief: a4u.com Career Management Platform

## 1. Project Overview
**a4u.com** is an AI-powered career management and resume-building platform designed to help professionals navigate complex recruitment processes using data intelligence. The platform specializes in translating professional experience into high-impact resumes and visualizing career progression.

## 2. Target Audience & Persona
The primary audience includes mid-to-senior level professionals seeking career transitions or retirement planning.
*   **Primary Persona:** Hong Gil-dong
*   **Profile:** 50-year-old Java Developer transitioning from a long career in the SI (System Integration) industry.
*   **Key Needs:** Professional resume modernization, career milestone visualization, and retirement benefit tracking.

## 3. Design System: "Executive Kinetic"
*   **Brand Personality:** Professional, trustworthy, efficient, and forward-moving.
*   **Visual Language:** 
    *   **Color Palette:** Deep Indigo (#4f46e5) as the primary brand color, supported by clean surfaces and subtle grays.
    *   **Typography:** Inter (Sans-serif) for high readability and a modern, technical feel.
    *   **Shape:** Rounded corners (8px) for a balanced, approachable yet structured look.

## 4. Key Features & Screens
### 4.1. Landing Page
A high-conversion entry point highlighting AI-driven intelligence and data tools for career growth.

### 4.2. User Dashboard
A central hub for career health, including a "Resume Completion Score," quick action cards, and an "Application Tracker" to manage job leads.

### 4.3. AI Resume Builder
A flexible creation tool allowing users to:
*   **Upload & Parse:** Import existing PDF/Word documents for AI-powered data extraction.
*   **Direct Entry:** Manually input and edit professional details with AI assistance.
*   **Live Preview:** Real-time visualization of the final resume document.

### 4.4. Career Timeline
An interactive visualization of a user's professional journey, from junior roles to senior leadership, categorizing milestones into Experience, Education, and Certifications.

## 5. Technical Requirements
*   **Responsive Design:** Optimized for both Desktop and Mobile (KR localized).
*   **Localization:** Full support for Korean language and professional terminology.
*   **AI Integration:** Real-time resume parsing and content suggestions.
